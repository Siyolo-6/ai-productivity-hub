## Project Overview

The **AI Workplace Productivity Assistant** combines three common workplace workflows in one easy-to-use interface:

- Draft professional emails in a selected tone.
- Summarize meeting notes and identify follow-up actions.
- Organize tasks into prioritized daily or weekly plans.

The interface follows a clean SaaS-inspired design with a dark charcoal background, pink accents, sidebar navigation, and responsive layouts.

> **AI integration note:** Real AI-generated responses require a configured AI provider. A frontend-only app cannot securely protect private API keys. Use a supported managed AI integration or a secure server-side proxy for production. Never commit API keys or secrets to GitHub.

## Features Implemented

### Smart Email Generator
- Create email drafts from user-provided context.
- Choose between **Formal**, **Friendly**, and **Persuasive** tones.
- Edit and copy the generated draft.

### Meeting Notes Summarizer
- Summarize pasted meeting notes into concise key points.
- Extract decisions, action items, owners, and deadlines when available in the source notes.
- Edit the summary before sharing it.

### AI Task Planner
- Organize tasks into a daily or weekly plan.
- Prioritize tasks using importance, deadlines, and available time.
- Review and adjust the proposed schedule.

### Dashboard and usability
- Responsive desktop, tablet, and mobile layout.
- Sidebar navigation between productivity tools.
- Dark charcoal surfaces with pink accents.
- Editable outputs and copy, regenerate, and clear actions where supported.
- Input validation, loading indicators, and useful empty states.
- Responsible AI disclaimer encouraging users to review generated content.
