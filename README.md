# AI Productivity Hub

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant using React, Tailwind CSS, and a clean pink-and-dark theme. Create a professional dashboard with sidebar navigation and three tools:

Smart Email Generator: Generate context-specific professional emails from user inputs, with Formal, Friendly, and Persuasive tones.

Meeting Notes Summarizer: Summarize pasted meeting notes and extract key points, decisions, action items, owners, and deadlines.

AI Task Planner: Create prioritized daily or weekly schedules from tasks, deadlines, and available hours.

Requirements:

Premium UI with dark charcoal backgrounds, vibrant pink accents, clean cards, subtle gradients, and responsive layouts.

Use structured prompts to generate relevant, context-aware AI outputs—not generic templates.

Make all generated results editable, with Copy, Regenerate, and Clear actions.

Include input validation, loading states, useful empty states, and a responsible AI disclaimer.

No backend, database, authentication, or paid integrations. Use local state and browser storage where appropriate.

For real AI-generated responses, integrate a configurable AI API through a frontend demo interface, clearly explaining that a secure backend is required to protect API keys in production. Never hardcode secrets.

Keep the implementation lightweight and functional. Build all three tools into one cohesive dashboard, prioritizing core features over unnecessary extras.
